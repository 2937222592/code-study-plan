## 1. 背景与目的

本平台定位为**面向编程初学者的「学习陪跑系统」**：提供确定的学习路线、按个人时间生成的学习计划、每个技能的精选学习资料、**课件学习与互动**，以及**上下文感知的 AI 学习助教**（学到不懂的可以问它）。

本文档定义第一个精做岗位——**AI 应用开发**——的完整学习内容与功能需求，作为内容制作与系统开发的依据。

**为什么首选该岗位：**
- 市场热度高：大模型应用开发是目前人才需求增长最快、最受关注的方向之一；
- 门槛相对友好：不需要深厚的数学/算法背景，Python 入门即可起步，初学者能较快做出可见成果；
- 与系统 AI 助教能力天然契合：教学内容与 AI 答疑场景高度一致，容易做出差异化体验；
- 可作为样板，验证「路线 + 计划 + 资料 + 课件 + AI 助教」闭环后再复制到其他岗位。

**核心差异化（为什么用户留在这里而不是直接去 B 站）：**
- 用户通过我们提供的视频链接去外部看视频，**看完即走，系统只是"流量中转站"**，无法沉淀任何东西；
- 解决方式：把视频配套的**课件以章节化页面在系统内展示**，用户可以在课件上**做标记、写笔记**，每个章节还有**讨论区**；
- 由此，用户"看到哪、标记了什么、笔记写了什么、讨论了什么"全部沉淀在系统里，形成**存在感、留存与社区萌芽**，课件本身也成为平台的内容资产。

## 2. 岗位定义

- **岗位名称**：AI 应用开发工程师（LLM Application Developer）
- **职责**：基于大模型 API 构建真实应用（对话机器人、知识库问答、智能体、自动化工具），负责 Prompt 设计、RAG 检索增强、Agent 编排、API 集成、部署与成本优化。
- **与相关岗位的区别**：
  - vs 算法/机器学习工程师：**不训练模型、不深究模型原理与数学**，聚焦应用层；
  - vs 传统后端开发：核心能力从"写业务逻辑"变为"与大模型交互并编排能力"。
- **目标人群**：会一点 Python 的初学者、想转行 AI 应用的开发者、在校学生。
- **学成目标**：能独立设计、开发并部署一个完整的 AI 应用（聊天机器人 / 知识库问答 / 智能体工具），拥有可展示的作品集。

## 3. 能力模型（学完应具备）

1. 能用 Python 调用大模型 API，正确处理请求与输出（含流式、结构化输出）；
2. 能设计高质量 Prompt（角色、指令、示例、格式约束）；
3. 能构建带界面/接口的 AI 应用（FastAPI + 简单前端 / 流式交互）；
4. 能实现 RAG 知识库问答，并处理检索质量、幻觉等常见问题；
5. 能实现多工具 Agent 编排（规划-调用-循环-终止）；
6. 能控制成本、评估效果并部署上线；
7. 能读官方文档、跟踪社区动态，具备持续学习能力。

## 4. 学习路径总览（7 个阶段）

| 阶段 | 主题 | 学习目标 | 阶段产出 |
|---|---|---|---|
| S0 | 认知与准备 | 理解岗位、搭好开发环境 | 环境就绪 + 项目仓库 |
| S1 | Python 编程基础 | 能独立写 Python 脚本 | 命令行小工具 |
| S2 | 大模型 API 与 Prompt | 能调 API、写好 Prompt | 「文案助手」 |
| S3 | 应用开发与工程化 | 能做带界面/接口的 AI 应用 | 网页聊天机器人 |
| S4 | RAG 知识库问答 | 能做文档问答应用 | 知识库问答应用 |
| S5 | Agent 智能体 | 能做多工具智能体 | 多工具小助手 |
| S6 | 部署评估与作品集 | 能上线完整项目 | 作品集项目 |

> 节奏目标：按每天投入 1 小时，8~10 周完成全部阶段。

## 5. 内容粒度与规范（每个技能"五件套"）

每个技能固定包含 5 类内容，**缺失任何一类视为内容不完整**：

1. **概念卡（本站速览）**：3~5 分钟可读完，包含
   - 一句话解释；
   - 生活化类比（降低理解门槛）；
   - 可直接运行的代码示例；
   - 「常见坑」清单（2~3 条）。
2. **精选外部资源**：1~3 条，含
   - 类型（视频 / 官方文档 / 图文教程）；
   - 来源、标题、URL；
   - 时长（视频）与难度标注；
   - 推荐理由（为什么选它、看哪一部分即可）。
3. **课件（对应视频资源）**：把推荐的视频配套课件整理成章节化页面，在系统内展示（详见第 7 节）。
4. **动手小任务**：20~60 分钟，包含
   - 任务描述（结合真实场景）；
   - 验收标准（做到什么程度算完成）；
   - 参考做法/思路（不提供完整答案，可引导 AI 点评）。
5. **FAQ（AI 助教知识库）**：3~5 个该技能初学者最常问的问题与标准讲解，供 AI 助教直接引用。

**内容写作规范**：
- 语言：中文，面向零基础/弱基础，避免术语堆砌；
- 每个概念卡先给"是什么 + 类比"，再给"怎么用 + 坑"；
- 代码示例必须可运行、注明依赖与运行方式；
- 资源以免费为主，视频优先选 B 站、官方文档优先选权威来源；
- **课件必须标注来源与授权方式**（见 7.6 版权合规）。

## 7. 课件模块（核心差异化功能）

### 7.1 定位与价值
- **问题**：用户点击外部视频链接后离开，学习过程零沉淀，系统没有存在感；
- **方案**：把推荐视频的配套课件整理为**章节化页面**在系统内展示，用户可**标记、做笔记**，每个章节有**讨论区**；
- **价值**：学习行为（进度、标记、笔记、讨论）全部沉淀在系统 → 提升留存与粘性；课件成为平台**内容资产**；讨论区成为**社区萌芽**。

### 7.2 课件结构
- 课件绑定到「技能-资源」层级（一个技能可有多份课件，对应不同视频）；
- 结构：**课件 → 章节（对应视频分段）→ 页面（图文/要点/代码）**；
- 每页字段：标题、正文/要点、代码示例、配图说明、所属章节、排序；
- 展示布局：左侧目录（章节/页面导航），右侧内容；支持全屏阅读；记录阅读进度（已读页数）。

### 7.3 标注与笔记
- **高亮标记**：选中课件正文文字 → 高亮（可取消），支持颜色区分（重点/疑问）；
- **页面笔记**：每个页面可添加多条笔记，自动记录所属页；
- **笔记中心**：个人「我的笔记」聚合页，按技能/章节分组，支持搜索与导出（Markdown）；
- **进度联动**：课件阅读进度计入学习进度与每日打卡。

### 7.4 章节讨论区
- 挂载点：每个课件章节一个讨论区；
- 功能：发帖、回复、点赞、按时间/热度排序；需登录后发言；
- 治理：管理员可置顶/删除/禁言；敏感词过滤；支持提问标记"已解决"；
- 与 AI 联动：讨论区提问可"转给 AI 助教"，AI 回答可引用具体课件页。

### 7.5 与打卡 / AI / 进度联动
- 学完一个课件章节 → 可打卡，计入每日任务；
- 笔记/标记数量计入个人学习统计；
- AI 助教上下文新增：当前课件页内容 + 用户在该页的笔记/标记。

### 7.6 来源与版权合规（重要，必须遵守）
- **原则**：只收录"允许使用"的课件——B 站开源课件（优先）或平台自制（兜底）；
- **来源策略（已确认）**：优先采用 B 站视频配套的开源课件（使用前核实开源/授权说明，并标注来源创作者与原视频链接）；若视频无配套课件或课件非开源，则由平台自制（不嵌入原视频，以图文页面呈现）；
- 每份课件必须标注：来源创作者、原视频链接、授权方式；
- 提供「侵权投诉/下架」入口与流程，收到有效投诉后 24 小时内处理；
- 平台不主张对他人课件拥有版权；对外商用前必须获得书面授权。

## 8. AI 助教集成点

**入口**：
- 技能卡片「问 AI」按钮（携带当前技能上下文）；
- 全局学习助手（跨阶段提问）；
- **课件页内**：选中文字 → 「问 AI」解释这段内容；
- **笔记联动**：用户笔记可让 AI 总结/扩展。

**助教行为规范**：
1. 用初学者能懂的语言，优先使用类比；
2. 回答时优先引用本站概念卡与课件页，再给外部资源链接；
3. 不直接代写完整答案；求助小任务时先给思路、再逐步引导；
4. 用户表示"没懂"时，换一种讲法，并自动将该技能标记为"待复习"。

**上下文输入**（每次提问自动携带）：
- 当前技能 ID/名称/难度；
- 当前阶段与整体进度；
- 用户历史提问与"没懂"标记；
- 当前课件页内容与用户该页笔记/标记；
- 关联的 FAQ 条目（作为知识库优先命中）。

**S0-S6 每个技能的 FAQ 即 AI 助教的基础知识库**，后续按用户提问持续扩充。

## 9. 学习计划与打卡机制

- 用户设置每日可投入时间（默认 1 小时）；
- 系统按阶段顺序生成周计划：每天 = 1~2 个技能（概念卡 + 精选资源 + 课件学习 + 小任务）；
- 完成当天任务后打卡，记录连续天数（streak）；
- 未完成任务自动顺延到次日；
- 每周日自动生成下周计划；AI 可基于进度生成"今日计划"说明。

## 11. 验收标准

1. **内容完整性**：7 阶段、约 37 个技能，每个技能五件套齐全（概念卡 / 资源 / 课件 / 小任务 / FAQ）；
2. **课件可用性**：S0~S6 关键技能均有课件（至少覆盖 S2-S4 核心技能），页面渲染正常、阅读进度可记录、标注与笔记可保存可回顾；
3. **讨论区可用**：每个章节可发帖/回复/点赞，敏感词过滤与管理员删除生效；
4. **版权合规**：所有课件均标注来源与授权方式，提供投诉下架入口（抽查通过）；
5. **可学性**：邀请 2~3 名初学者按路线走完 S0~S2，能独立完成阶段小任务；
6. **资源有效性**：所有外部链接可访问，视频时长、难度标注准确；
7. **AI 助教效果**：对 FAQ 中问题的回答准确率 ≥ 90%（人工抽测），且不直接代写完整答案；
8. **计划可行性**：按每日 1 小时，S0~S6 可在 8~10 周完成（先小范围试跑验证）。
